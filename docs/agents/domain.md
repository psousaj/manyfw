# Domain Docs

ManyFW uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant decisions in `docs/adr/` when that directory exists.
- If these files do not exist, proceed without treating their absence as a problem.

## Vocabulary

Use terms from the domain glossary when one exists. If a required concept is not
defined, surface the gap for domain modeling rather than silently inventing a
conflicting term.

## Decisions

Record an ADR only for a hard-to-reverse, surprising trade-off. Keep
implementation details out of `CONTEXT.md`; it is a domain glossary, not a spec
or scratchpad.
