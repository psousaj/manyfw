# Issue tracker: GitHub

Issues and PRDs for this repo live as GitHub issues.

## Repository

- Owner: `psousaj`
- Repository: `manyfw`
- PRs are not treated as a separate triage request surface.

## Conventions

- Create, read, list, comment, and edit issues with the GitHub CLI (`gh`).
- Apply and remove labels without replacing unrelated labels.
- Close issues with an explicit reason and comment when appropriate.
- Issue numbers may also identify pull requests; resolve the object before triaging.

## Triage

Triage state and category labels are defined in `docs/agents/triage-labels.md`.
